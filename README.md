
# Project Name
Fitlog-Assignment-6

# Short Description
FitLog is a dark-themed workout library and gym companion that allows users to explore workouts, view detailed exercise information, add exercises to their daily plan, save workouts for later, and track their workout progress.

# Technology Used
Next.js Build the UI
App router(Next.js) + Handle page navigation
Tailwind CSS + Any component library Styling and responsiveness

# Key Features
1. Workout Library — Browse workouts with muscle groups, equipment, duration, calories, and ratings.
2. Workout Details — View detailed information including description, difficulty, sets, reps, specifications, and instructions.
3. My Plan — Add up to five workouts to today's plan and manage them from one place.
4. Save for Later — Save favorite workouts and access them from the Saved section.
5. Search & Sort — Search workouts and sort them by duration, calories, or rating.
